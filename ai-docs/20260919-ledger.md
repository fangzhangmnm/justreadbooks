## 2. 真机总单（一批 = 交付；user 有空再测，别催）

设备：手机（SE2 基准）+ 电脑上的 MyLlamaReborn 脚本。

1. 开 `/dev/` → 书架空态 → 云图标 → 连接 OneDrive（personal 账号）→ 回来书架列出 `Apps/JustReadBooks/` 根 + `ai-dropbox/` 夹；`session.json` / `library.json` **不该出现**。
2. 进 `ai-dropbox/` → 列表视图长书名整行、副标题（状态头，首开后才有）、未读点。
3. 开一本装订书 → 直进第 1 篇（不是「（开头）」）→ 翻几章 → 顶栏章名跟着变。
4. 电脑上跑一次 `bind_book.py` 同名覆盖 → 手机**不刷新**、正在读的章不动 → 等 ≤60s 或切后台回来 → 出「这本书有更新」chip → 点「刷新」→ 同章新内容。
5. 没动过的情况：开书后立刻切后台，电脑覆盖，回前台 → 静默换底（状态行「已更新到云端最新版」），无 chip。
6. 关 app 半天再开 → 秒开上次那本、回到原位（无蒙层、不等网）。
7. 飞行模式 → 开已打开过的书 ✓；开纯云端书 → 诚实「本机没有这本书，云端也够不着」。
8. 书架 ⋯ → 「留一份离线」一本纯云端书 → 徽章变已同步；「卸载本地」反向。
9. 上传：拖一个 GBK 的 txt → 书架出现、能开、不乱码；OneDrive 网页里看到是 UTF-8。
10. 大件：开一本 > 20 MB 的（主蒸馏全量）→ 弹「这本书很大」→ 仍要打开 → 能不能开动、多久（回写 §4 阈值）。
11. 设置：字号 / 行宽两档 / 主题 / 书架布局切卡片 → 都即时生效；「清缓存重启」回来版本号对。
13. 沉浸阅读：开书后顶栏藏着；中间轻点露出、再点收；左右轻点什么都不发生；滚动即收；从书架 / 设置回来顶栏藏着。
14. 点书架 / 点一本书：登录状态下也**不等网络**（0.1.2 修；之前 await 了云端往返）。
15. 书架 ⋯ → 改名 / 移动一本**没在读**的书 → 再开它位置还在、切章规则还在（0.1.3，gallery 0.3.1 onRenamed）；改名框里不带 `.txt`。
16. 删掉「上次那本」再开 app → 直接进书架、不弹「本机没有这本书」；「继续读」条里点一本开不了的 → 本次不再出现。
17. 装订书的目录：`## E1v3 / 原文` 缩在 `# 篇名` 下一级。
12. 登出 → 书的本机副本还在、能读；再登录 → 位置从云端回来。
